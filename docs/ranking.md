# MyAnimeList Ranking Types

This reference lists the ranking types available for anime and manga.

## Anime rankings

| Ranking type | Description |
| --- | --- |
| `all` | Top Anime Series |
| `airing` | Top Airing Anime |
| `upcoming` | Top Upcoming Anime |
| `tv` | Top Anime TV Series |
| `ova` | Top Anime OVA Series |
| `movie` | Top Anime Movies |
| `special` | Top Anime Specials |
| `bypopularity` | Top Anime by Popularity |
| `favorite` | Top Favorited Anime |

## Manga rankings

| Ranking type | Description |
| --- | --- |
| `all` | All |
| `manga` | Top Manga |
| `novels` | Top Novels |
| `oneshots` | Top One-shots |
| `doujin` | Top Doujinshi |
| `manhwa` | Top Manhwa |
| `manhua` | Top Manhua |
| `bypopularity` | Most Popular |
| `favorite` | Most Favorited |
